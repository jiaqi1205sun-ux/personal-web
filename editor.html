📖 使用说明

  1. 编写文章：在左侧编辑区输入 Markdown 格式的文章内容
  2. 实时预览：右侧会自动渲染预览效果，与博客详情页完全一致
  3. 加载模板：点击「加载模板」按钮可以加载常用语法示例
  4. 导出发布：点击「导出 HTML 代码」，复制内容，然后：
    1. 打开 detail.html 文件
    2. 找到 articles 数组，添加新的文章对象
    3. 将复制的 content 内容粘贴进去
    4. 设置好 id、tag、date、readtime、title 等字段
    5. 更新 prev 和 next 的导航关系
